# Лицензии изображений

На сайте нет фотографий, стоков и чужих иллюстраций.

- Контентных `<img>` нет. Текст «ПД» в шапке — это буквы в блоке, не картинка, атрибут alt не нужен.
- Декоративный шум в `app/globals.css` (класс `.noise-overlay`) — встроенный SVG data-uri, нарисованный в этом проекте. Отдельной лицензии нет.
- Остальная графика — CSS и собственные SVG-фрагменты в компонентах.
- Файлы `public/file.svg`, `public/globe.svg`, `public/next.svg`, `public/vercel.svg`, `public/window.svg` — шаблон create-next-app. Интерфейс их не показывает. Если их начнут использовать, это знаки Next.js и Vercel, а не стоковые фото.
